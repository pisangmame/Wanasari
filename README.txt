PISANG MAME WEBSITE — VERSI MOBILE FRIENDLY

Isi:
- index.html
- assets/logo-pisang-mame.jpeg
- assets/foto-menu-pisang-mame.jpeg (foto menu yang diberikan)
- assets/menu-takeaway.pdf

UPLOAD:
1. Buka repository di akun GitHub pisangmame.
2. Upload isi folder ini, bukan ZIP saja.
3. Pastikan index.html berada di root repository dan folder assets ikut di-upload.
4. Settings > Pages > Deploy from a branch.
5. Branch main, folder /(root), klik Save.

Catatan: ikon brand online menggunakan CDN Simple Icons dan memerlukan koneksi internet. GoFood ditampilkan dengan ikon brand Gojek dan nama layanan GoFood.
