PISANG MAME — WEBSITE REDESIGN

Isi folder:
- index.html (desain website baru)
- assets/menu-takeaway.pdf (menu PDF asli)
- assets/logo-pisang-mame.jpeg (file logo, tidak ditampilkan besar di halaman)

CARA GANTI WEBSITE DI REPOSITORY GITHUB YANG SUDAH ADA:
1. Ekstrak ZIP ini di komputer.
2. Buka repository GitHub kamu: https://github.com/pisangmame/Wanasari
3. Klik Add file > Upload files.
4. Dari folder hasil ekstrak, pilih index.html dan folder assets (beserta file di dalamnya).
5. Jika GitHub bertanya file dengan nama sama akan diganti, setujui/Commit changes.
   Pastikan index.html berada langsung di halaman utama repository, bukan di dalam folder pisang_mame_redesign.
6. Tunggu sebentar lalu refresh website GitHub Pages.
7. Jika Pages belum aktif: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Tautan website yang diharapkan: https://pisangmame.github.io/Wanasari/

Catatan: banner menulis “diskon hingga 60%” dengan catatan bahwa promo harus tersedia dan memenuhi syarat di aplikasi. Pastikan klaim ini sesuai dengan promo yang sedang berlaku sebelum dipublikasikan.
